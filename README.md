# MarkdownTableGenerator

Project is still a work in progress, but is functional. 

Programmatically generates Markdown formatted tables from data files. Supported file formats: CSV, NumPy, and Excel (.xlsx) files. Inserts table into Markdown file at specific line number or at end of file.

Class `MarkdownTable` and its Python caller `main.py` generate Markdown table as specified above. Package can be installed as an executable package with command `markdown-table`.
